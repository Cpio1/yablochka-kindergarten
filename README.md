# Детский сад «Яблочко» — лендинг

Next.js 16 + TypeScript + Tailwind CSS 4. Русская версия — `/`, казахская — `/kk`.

```bash
npm install
npm run dev        # разработка
npm run typecheck  # проверка TypeScript
npm run build      # production-сборка
```

## Где что менять

- `lib/site.ts`: телефон, часы работы, Instagram, WhatsApp (`whatsapp: null`, пока номер не подтверждён), документы, ссылка 2GIS.
- `lib/i18n.ts`: все тексты RU/KK.

## Медиафайлы

Положите файлы в `public/` или `public/media/` и пересоберите проект. Сайт найдёт их при сборке:

| Файл | Куда попадает |
|---|---|
| `main-page.(png|jpg|jpeg|webp)` | первый экран (вместо иллюстрации яблока) |
| `main-page2.(jpg|png|webp)` или `main-page2.(mp4|webm|mov)` | раздел «О садике» |
| `main-page2-poster.jpg` | обложка видео (необязательно) |
| `logo.png` | шапка (прозрачный фон сохраняется) |
| остальные фото | галерея (по алфавиту), пункт меню «Галерея» появляется автоматически |

Логотипы, иконки, обложки и точные дубликаты в галерею не попадают. Если превью обрезает лица, добавьте поправку
кадрирования в `focusOverrides` (`lib/media.ts`).
