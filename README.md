# Детский сад «Яблочко» — лендинг

Next.js 16 + TypeScript + Tailwind CSS 4. Русская версия — `/`, казахская — `/kk`.

```bash
npm install
npm run dev        # разработка
npm run typecheck  # проверка TypeScript
npm run build      # production-сборка
```

## Где что менять

- `lib/site.ts`: телефон, часы работы, Instagram, WhatsApp (`whatsapp: null`, пока номер не подтверждён),
  документы (`documentsFolder` — ссылка на папку, `documents` — отдельные файлы с подписью по содержанию),
  меню (`menu` — файл или ссылка с датой; тогда в «Питании» появится «Посмотреть меню»), ссылка 2GIS.
  Раздел «Документы» и пункт меню появляются только при наличии папки или файлов.
- `lib/i18n.ts`: все тексты RU/KK, включая «Вопросы родителей». Неподтверждённые сведения (адрес, дни недели,
  названия групп, блюда, стоимость, наличие мест) не публикуются — тексты предлагают уточнить их у садика.

## Медиафайлы

Положите файлы в `public/` или `public/media/` и пересоберите проект. Сайт найдёт их при сборке:

| Файл | Куда попадает |
|---|---|
| `main-page.(png|jpg|jpeg|webp)` | первый экран (вместо иллюстрации яблока) |
| `main-page2.(jpg|png|webp)` или `main-page2.(mp4|webm|mov)` | раздел «О садике» |
| `main-page2-poster.jpg` | обложка видео (необязательно) |
| `logo.png` | шапка (прозрачный фон сохраняется) |
| остальные фото | галерея (по алфавиту), пункт меню «Галерея» появляется автоматически |

Логотипы, иконки, обложки и точные дубликаты в галерею не попадают. В `photoMeta` (`lib/media.ts`) по имени файла
можно задать кадрирование превью (`focus`) и короткую подпись RU/KK (`caption`) — только по тому, что видно на снимке.
Когда фото появятся, уточните вступление галереи (`gallery.intro` в `lib/i18n.ts`) по их реальному содержанию.
